# Cruscotto HR
Sistema di Monitoraggio HR della Pubblica Amministrazione.

## Stack
- Frontend: React + TypeScript + Vite + Tailwind + shadcn/ui + Recharts
- Backend/DB: Supabase self-hosted (PostgreSQL) via Docker

## Sviluppo
npm install npm run dev
App su http://localhost:8080

## Configurazione
Variabili in `.env`:
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`
