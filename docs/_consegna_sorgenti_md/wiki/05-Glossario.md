# 5. Glossario

[◀ Torna all'indice](Home)

Raccolta dei termini ricorrenti nell'applicazione e nella presente documentazione.

| Termine | Significato |
|--------|-------------|
| **Scheda** | Vista tematica dell'applicazione che raccoglie indicatori, grafici ed eventuali tabelle su un determinato argomento. |
| **Indicatore** | Valore di sintesi esposto in una scheda (ad esempio un totale o un rapporto) utile alla lettura del fenomeno. |
| **Dimensione (D1–D6)** | Ciascuna delle sei aree della gestione del personale: D1 Rilevazione e classificazione, D2 Programmazione del fabbisogno, D3 Recruiting, D4 Sviluppo professionale, D5 Rewarding e carriera, D6 Capacity building e performance. |
| **Indice** | Misura calcolata su una dimensione, a partire dai dati delle fonti. |
| **Indice di sintesi** | Indice che riassume gli indici componenti della propria dimensione (ad esempio IGF per la D2, IDC per la D5). |
| **Indice componente** | Indice che concorre al calcolo di un indice di sintesi. |
| **Score** | Punteggio da 0 a 100 che rende confrontabili indici con unità di misura diverse. Non è una percentuale. |
| **Giudizio** | Lettura dello score in quattro fasce: Basso (sotto 25), Moderato (da 25 a 49), Buono (da 50 a 74), Eccellente (da 75). |
| **Variazione in punti** | Differenza di score rispetto all'anno precedente (ad esempio «+3 punti vs 2023»). |
| **Scomposizione formula** | Pannello della card che mostra, passo per passo, come si calcola l'indice e come diventa score. |
| **Vista Executive** | Quadro d'insieme degli indici delle sei dimensioni. |
| **Vista Sintetica** | Pagina di dettaglio di una dimensione, con tutte le card dei suoi indici. |
| **KPI** | Indicatore chiave di prestazione della Riforma PA; può essere abilitante o di successo. |
| **Tipo di sintesi** | Modo in cui un KPI è calcolato: formula complessiva oppure media semplice. |
| **Filtro a cascata** | Insieme di filtri collegati tra loro: la selezione di una voce aggiorna automaticamente le voci dipendenti, mostrando solo le combinazioni valide. |
| **Ente** | Amministrazione a cui sono associati i dati visualizzati. |
| **Ente accreditato in SIPrO** | Ente che partecipa al SIPrO e di cui sono quindi disponibili i dati SIPrO. |
| **Perimetro dei dati** | Ambito dei dati che un utente è autorizzato a visualizzare, determinato automaticamente in base alle sue abilitazioni. |
| **Benchmark** | Confronto tra più enti sugli stessi indicatori. |
| **Single sign-on (SSO)** | Modalità di accesso che consente di autenticarsi con le credenziali aziendali già in uso per gli altri servizi interni. |
| **Profilo / Ruolo** | Insieme di autorizzazioni associate all'utente, che determina l'ambito di visibilità e le funzioni disponibili. |
| **Pannello di gestione** | Area riservata ai profili amministrativi per attivare o disattivare schede e indici e consultare statistiche e registri. |
| **Scheda attiva / disattivata** | Stato di disponibilità di una scheda o di un indice, gestito dagli amministratori tramite il pannello di gestione. |
| **Dati dimostrativi (mock-up)** | Dati presentati a scopo illustrativo, in attesa della disponibilità dei dati definitivi; sempre segnalati da un apposito avviso. |
| **Esportazione** | Funzione che consente di scaricare i dati di una tabella in CSV, Excel o PDF. |
| **Avviso di aggiornamento** | Notifica che segnala la disponibilità di una nuova versione dell'applicazione e invita a ricaricarla. |
